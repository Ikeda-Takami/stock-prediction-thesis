# Stock Prediction Thesis

ニュース記事の要約（LLM）とLSTMを用いた株価予測モデルの卒業研究プロジェクトです。

## 📂 ディレクトリ構成

- `src/`: ソースコード一式
  - `01_...`: データ取得・前処理
  - `05_evaluate_prediction_LSTM.py`: LSTMモデルによる予測実行スクリプト
- `data/`: 実験用データ
  - **Note:** GitHubの容量制限のため、**2024年8月分** のデータのみアップロードしています。
- `requirements.txt`: 必要なライブラリ一覧

## 🚀 環境構築 (Setup)

以下のコマンドで必要なライブラリをインストールしてください。

```bash
pip install -r requirements.txt
